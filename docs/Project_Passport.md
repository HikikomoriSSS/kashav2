## 1. Введение и Общая информация (КТ 1)

### 1.1 Тема и цель проекта
* **Тема:** Архитектурный 3D веб-конфигуратор — интерактивное веб-приложение для проектирования зданий и помещений в реальном времени.
* **Цель:** Предоставить пользователям (как профессионалам, так и любителям) удобный инструмент для создания 3D-моделей помещений, планировки и подбора интерьерных решений без необходимости установки тяжелого ПО.

### 1.2 Анализ рынка (TAM / SAM / SOM)
* **PAM (Potential Available Market):** ~500 млн пользователей по миру.
* **TAM (Total Addressable Market):** ~50 млн пользователей.
* **SAM (Serviceable Available Market):** ~5 млн пользователей.
* **SOM (Serviceable Obtainable Market):** ~50 000 пользователей.

## 2. Стек технологий и Архитектура (КТ 4 / КТ 5)

| Категория | Выбранное решение | Обоснование |
| :--- | :--- | :--- |
| **3D Rendering** | Three.js (React Three Fiber) | Быстрая загрузка в браузере, интеграция с React. |
| **Frontend** | React + TypeScript | Высокая производительность при частых обновлениях UI. |
| **State Management** | Zustand | Легковесность при работе с 3D-сценой. |
| **Backend** | Node.js (NestJS) | Единый стек TypeScript на Front/Back. |
| **Database** | PostgreSQL + Redis | Поддержка `JSONB` для схем помещений + Redis. |
